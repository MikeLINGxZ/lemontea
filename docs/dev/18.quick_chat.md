# quick chat

## 目标

为项目新增“快速对话”功能，用户通过快捷键直接唤出对话窗口，快速选择“继续最新对话”或“新建对话”。

## 功能说明

### 1. 触发方式

- 用户按下全局快捷键即可唤出“快速对话”窗口
- 该窗口为浮层形式，不影响当前工作区
- 支持快捷键再次关闭或按 `Esc` 关闭

### 2. 窗口结构

- 左侧：对话模式选择区
  - 两个选项：`继续` | `新建`
  - 用户可使用 `Tab` 键在两项之间切换
  - 也支持鼠标点击切换
- 右侧：对话内容/操作区
  - 若选择 `继续`：展示最新对话摘要与继续会话入口
  - 若选择 `新建`：展示新对话的准备状态或空白输入区

### 3. 选项语义

- `继续`
  - 代表从“对话列表中最新的对话”继续
  - 保持该对话上下文、历史、记忆等
  - 进入后直接打开最新会话，不创建新会话
- `新建`
  - 代表开始一个全新的对话
  - 不继承任何现有对话上下文
  - 创建一个新的对话会话实例

## 交互细节

### 4. 键盘交互

- 默认焦点应在左侧选项区
- `Tab` 切换：如果当前焦点在“继续”，按 `Tab` 切换到“新建”，反之亦然
- 按 `Enter` 确认当前选项
- `Esc` 关闭弹窗

### 5. 默认状态

- 打开时默认选中 `继续`
- 如果当前不存在任何历史对话，默认直接选中 `新建`
- 用户切换后应即时反馈当前选择状态

### 6. 异常与边界

- 若没有历史对话：`继续` 状态不可用或显示为“暂无历史对话”
- 若当前最新对话已关闭或不可继续，应提示并自动转为 `新建`
- `新建` 必须保证创建的是一条全新会话，不带任何旧上下文

## 验收标准

1. 用户能通过快捷键唤出快速对话窗口
2. 左侧可见 `继续` 与 `新建` 两个选项
3. `Tab` 能在两项间切换，`Enter` 能确认选择
4. 选择 `继续` 时进入最新会话；选择 `新建` 时创建新会话
5. `Esc` 或快捷键可关闭窗口
6. 无历史对话时，“继续”不可用并自动回退到“新建”

## 建议补充

- 可以在右侧加一行小提示：`继续：从最新对话接着聊` / `新建：开启新的对话`
- 如果有“对话列表”功能，窗口可以在右侧显示“最新对话摘要”以提高可用性
